# Modelo de Base de Datos y Seguridad — Motrik

Este documento detalla el esquema relacional en PostgreSQL alojado en Supabase, sus claves foráneas, restricciones de integridad y políticas de Row Level Security (RLS).

---

## 2. Descripción de Entidades

### 2.1 `public.usuarios`
Representa a los actores del sistema (conductores, administradores de talleres y mecánicos):
- `id` (`UUID PRIMARY KEY DEFAULT gen_random_uuid()`): Identificador único compatible con Supabase Auth.
- `nombre` (`TEXT NOT NULL`): Nombre completo o razón social.
- `correo` (`TEXT UNIQUE NOT NULL`): Correo electrónico del usuario.

### 2.2 `public.vehiculos`
Garaje virtual del usuario:
- `id` (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).
- `usuario_id` (`UUID REFERENCES public.usuarios(id) ON DELETE SET NULL`).
- `marca` (`TEXT NOT NULL`), `modelo` (`TEXT NOT NULL`), `ano` (`INTEGER NOT NULL`).
- `placa` (`TEXT NOT NULL UNIQUE`): Identificador vehicular en Colombia (ej. `KDM-482`).
- `kilometraje` (`INTEGER DEFAULT 0`): Odómetro actual en kilómetros.
- `motor`, `combustible`, `transmision`, `color`, `imagen_url`.
- `soat_vencimiento` (`TEXT`): Fecha límite en formato `YYYY-MM-DD`.
- `tecno_vencimiento` (`TEXT`): Fecha límite de revisión técnico-mecánica.

### 2.3 `public.repuestos`
Catálogo de autopartes:
- `id` (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).
- `nombre` (`TEXT NOT NULL`), `marca` (`TEXT NOT NULL`), `categoria_vehiculo` (`TEXT NOT NULL`).
- `precio` (`NUMERIC NOT NULL`), `precio_anterior` (`NUMERIC`).
- `calificacion` (`NUMERIC(2,1)`), `resenas_count` (`INTEGER`), `stock` (`INTEGER`).
- `imagen_url` (`TEXT`), `imagenes` (`TEXT[]`).
- `compatibilidad` (`TEXT`): Modelos compatibles o `'Universal'`.
- `especificaciones` (`JSONB`): Ficha técnica flexible (material, posición, garantía).
- `envio_gratis` (`BOOLEAN DEFAULT false`).

### 2.4 `public.registros_bitacora`
Historial de mantenimientos técnicos:
- `id` (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).
- `vehiculo_id` (`BIGINT REFERENCES public.vehiculos(id) ON DELETE CASCADE`).
- `fecha` (`TIMESTAMPTZ DEFAULT now()`).
- `descripcion_cambio` (`TEXT`): Resumen y metadatos del servicio.
- `pieza_actualizada` (`TEXT`): Nombre de la autoparte instalada.
- `repuesto_id` (`BIGINT REFERENCES public.repuestos(id) ON DELETE SET NULL`).
- `titulo`, `descripcion`, `kilometraje`, `taller`, `costo`.

### 2.5 `public.mecanicos`
Directorio de talleres certificados:
- `id` (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).
- `usuario_id` (`UUID REFERENCES public.usuarios(id) ON DELETE SET NULL`).
- `especialidad` (`TEXT NOT NULL`): Lista separada por comas (ej. `'Frenos, Suspensión'`).
- `ubicacion` (`TEXT NOT NULL`): Zona y dirección física (ej. `'Chapinero · Cra 13 #54-21'`).
- `calificacion_promedio` (`NUMERIC(2,1)`), `foto_url`, `telefono`, `horario`, `anos_experiencia`, `descripcion`.

### 2.6 `public.valoraciones`
Reseñas de clientes hacia talleres:
- `id` (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).
- `mecanico_id` (`BIGINT REFERENCES public.mecanicos(id) ON DELETE CASCADE`).
- `cliente_id` (`UUID`).
- `puntuacion` (`NUMERIC(2,1) NOT NULL DEFAULT 5.0`).
- `comentario` (`TEXT`), `fecha` (`TIMESTAMPTZ DEFAULT now()`).
- **Restricción Crítica**:
  ```sql
  CONSTRAINT valoraciones_cliente_id_fkey FOREIGN KEY (cliente_id) REFERENCES public.usuarios(id) ON DELETE SET NULL
  ```
  *Nota*: Esta nomenclatura exacta es obligatoria para satisfacer la consulta relacional de PostgREST en el frontend (`cliente:usuarios!valoraciones_cliente_id_fkey(nombre)`).

## 3. Políticas de Seguridad (Row Level Security - RLS)

Todas las tablas cuentan con RLS activado:
1. **Lectura Pública**: Los repuestos, talleres y valoraciones son accesibles tanto para usuarios anónimos (`anon`) como autenticados (`authenticated`) mediante `FOR SELECT USING (true)`.
2. **Registro de Bitácora**: Se autoriza la inserción controlada de mantenimientos desde la interfaz con `FOR INSERT WITH CHECK (true)`.
3. **Actualización de Vehículos**: Se autorizan actualizaciones de kilometraje y fechas de documentos con `FOR UPDATE USING (true)`.
