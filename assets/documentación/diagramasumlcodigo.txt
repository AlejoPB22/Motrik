Diagramas de Secuencia
Búsqueda de un repuesto por vehículo:
@startuml
skinparam maxMessageSize 150
actor Usuario
participant "Interfaz\n(React/Next.js)" as Frontend
participant "Backend\n(Next.js API)" as Backend
database "Base de Datos\n(Supabase)" as BD

Usuario -> Frontend: Ingresa datos del vehículo (Buscador)
activate Frontend

Frontend -> Backend: Petición GET (Búsqueda de repuestos)
activate Backend

Backend -> BD: Ejecuta query por nicho específico
activate BD

BD --> Backend: Retorna componentes correspondientes
deactivate BD

Backend --> Frontend: Envía datos JSON formateados
deactivate Backend

Frontend --> Usuario: Muestra catálogo categorizado
deactivate Frontend
@enduml

Registro en la Bitácora de Mantenimiento:
@startuml
skinparam maxMessageSize 150
actor Usuario
participant "Interfaz\n(React)" as Frontend
participant "Backend\n(Next.js API)" as Backend
database "Base de Datos\n(Supabase)" as BD

Usuario -> Frontend: Completa formulario (pieza, fecha) y envía
activate Frontend

Frontend -> Backend: Petición POST (Nuevo registro)
activate Backend

Backend -> Backend: Valida sesión del usuario (Seguridad Supabase)

Backend -> BD: INSERT en tabla de bitácora
activate BD

BD --> Backend: Confirma inserción exitosa
deactivate BD

Backend --> Frontend: Retorna status 200 (Éxito)
deactivate Backend

Frontend --> Usuario: Actualiza vista del control histórico
deactivate Frontend
@enduml

Enlace directo con taller aliado para repuestos (WhatsApp / RNF-03):
@startuml
skinparam maxMessageSize 160
skinparam shadowing false
skinparam roundcorner 6
skinparam defaultFontName "Segoe UI", Arial, sans-serif

actor "Usuario\n(Cliente)" as Usuario
participant "Interfaz\n(Next.js / Modal)" as Frontend
participant "Servicio Directorio\n(Taller Asignado)" as Directorio
participant "API Externa\n(WhatsApp)" as WhatsApp

Usuario -> Frontend: Clic en "Contactar Taller" para repuesto
activate Frontend

Frontend -> Directorio: getTallerAsignado(categoria, "Cartagena")
activate Directorio

Directorio --> Frontend: Retorna datos del taller (Nombre, WhatsApp, Sede)
deactivate Directorio

Frontend --> Usuario: Despliega modal de contacto B2B (Sin pasarela de pago)

Usuario -> Frontend: Clic en "Iniciar Chat por WhatsApp"

Frontend -> WhatsApp: Redirige con enlace wa.me (mensaje prellenado con pieza y auto)
activate WhatsApp

WhatsApp --> Usuario: Abre chat directo para coordinar adquisición e instalación
deactivate WhatsApp

deactivate Frontend
@enduml

  :Omitir vinculación de pieza;
